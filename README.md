# 浮光

> 把时间留给重要的事，也把生活轻轻收藏。

浮光是一款自然系视觉风格的个人生活与成长管理软件。它将专注计时、任务日历、日常记账、生活记录和成长计划放进同一个安静的空间，帮助你看见时间流向、整理生活节奏，并保存每个阶段留下的痕迹。

## 功能

### 今日总览

- 汇总今日专注时间、待办任务和本月结余
- 显示每日自动轮换的好言好句
- 今日速记自动保存，无需手动提交
- 查看最近的时间记录和当天正式任务

### 专注计时

- 从 `00:00` 开始的正向计时
- 最小化或切换到后台后仍按真实时间计算
- 支持暂停、继续、重置和结束记录
- 结束后自动计入今日专注和生活记录
- 右侧同步展示“今日应做”任务

### 记账本

- 记录收入、支出、分类、日期和备注
- 自动统计本月收入、支出与结余
- 查看和删除最近账目

### 任务日历

- 在月历中直接添加任务
- 支持任务时间和分类
- 点击任务即可完成，再次点击可以恢复
- 今日任务会同步到总览和专注页面

### 成长计划

- 创建阶段式学习与成长路线
- 阶段名称和类型均可自由定义
- 直接在表格中编辑类型与成长内容
- 设置待开始、进行中、已完成或暂时搁置
- 输入 `173/200` 等实际完成量，自动计算百分比与进度条
- 达到总量后自动标记为已完成

### 生活记录

- 记录工作、学习、生活、运动和娱乐时间
- “人间烟火账”展示所选月份的支出去向
- “光阴落处”展示本周或所选月份的时间分配
- 按月份回看历史收支与生活片段
- 一键导出当月收支、生活记录和速记纪念册

## 设计风格

浮光采用低饱和的自然系二次元视觉语言：晨雾湖山背景、鼠尾草绿与雾蓝配色、半透明玻璃卡片和舒缓的背景动效。界面同时适配桌面与移动尺寸，并支持系统“减少动态效果”设置。

- JavaScript

## 本地开发

环境要求：Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

浏览器访问 Vite 输出的本地地址，通常为：

```text
http://localhost:5173
```

## 构建网页版本

```bash
npm run build
```

构建结果会生成在 `dist/` 目录。

## 运行桌面版本

```bash
npm run desktop
```

## 构建 Windows 安装包

```bash
npm run desktop:build
```

Windows 安装包由 Electron Builder 生成。发布安装程序时，建议将 `.exe` 上传到 GitHub Releases，不要直接提交到源码仓库。

## 数据保存

浮光采用本地优先设计，任务、账目、速记、生活记录和成长计划默认保存在当前设备中，不会自动上传到服务器。

请注意：

- 卸载或更新软件通常不会主动删除用户数据。
- 清理应用数据或浏览器存储可能导致数据丢失。
- 建议定期在“生活记录”中导出月度纪念册进行备份。

## 隐私

浮光目前没有账户、云同步或数据分析服务。所有个人数据默认仅保存在本机。
